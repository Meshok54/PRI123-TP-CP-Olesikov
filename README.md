# Государственная система «Кадастровое управление»

Данный проект — веб-приложение на платформе ASP.NET Core MVC и СУБД MySQL, предназначенное для ведения кадастрового учета объектов недвижимости (участков, зданий, помещений), обработки заявлений граждан на регистрацию/обновление имущества, а также генерации официальных кадастровых выписок в PDF с имитацией ЭЦП.

Курсовой проект по предмету **«Технологии Программирования»**  
**Разработчик:** студент группы ПРИ-123 Олесиков Михаил.

---

## 1. Технологический стек

* **Бэкенд:** C# 12, .NET 8.0 (ASP.NET Core MVC).
* **База данных:** MySQL Server (версии 8.0).
* **Доступ к данным (ORM):** Entity Framework Core 8.0 (`Pomelo.EntityFrameworkCore.MySql`).
* **Безопасность:** Хэширование паролей по алгоритму **BCrypt** (`BCrypt.Net-Next`).
* **Генерация документов:** **iTextSharp.LGPLv2.Core** (динамическое формирование PDF выписок).
* **Тестирование:** **NUnit 3**, **Moq** (изоляция зависимостей), `EF Core InMemory` (изоляция БД).

---

## 2. Ролевая модель и возможности

1. **Гражданин (`Citizen`):**
   * Регистрация с указанием паспорта, авторизация, личный профиль.
   * Просмотр своего зарегистрированного имущества.
   * Подача заявлений на **Регистрацию** (нового объекта) или **Обновление** (существующего объекта) с прикреплением документов.
   * Заказ подробных кадастровых выписок, скачивание их в формате PDF и отправка на email.
2. **Сотрудник Росреестра (`Employee`):**
   * Мониторинг реестра всех поданных заявлений граждан.
   * Взятие заявлений на проверку, изучение прикрепленных файлов.
   * **Одобрение заявлений:** для «Регистрации» система генерирует уникальный кадастровый номер формата `XX:XX:XXX:XXXX` и создает объект; для «Обновления» — обновляет данные с записью истории изменений.
   * **Отклонение заявлений** с указанием официального комментария-причины.
   * Полнотекстовый поиск объектов по адресу, номеру или владельцу.
3. **Администратор (`Admin`):**
   * Все права сотрудника.
   * Управление пользователями: просмотр реестра учеток, повышение граждан до сотрудников, изменение рабочих отделов, удаление аккаунтов (с каскадной валидацией связей).

## 3. Как запустить проект локально

### Предварительные требования
Установите на ПК:
1. **.NET SDK 8.0**
2. **MySQL Server 8.0+**
3. Среду разработки (**Visual Studio 2022**, **Rider** или **VS Code**).
4. SQL-клиент (**MySQL Workbench** или **DBeaver**).

### Шаг 1. Создание базы данных
1. Откройте ваш SQL-клиент и подключитесь к серверу MySQL.
2. Выполните скрипт создания базы данных:
   `Database/Scripts/scriptCreate.sql`
3. Скрипт создаст БД `cadastral_management`, 9 связанных таблиц, ограничения внешних ключей и 17 оптимизирующих индексов.

### Шаг 2. Настройка подключения
Откройте файл `Cadastral Management/appsettings.json` и укажите параметры подключения к вашему локальному серверу MySQL:

```json
"ConnectionStrings": {
  "DefaultConnection": "Server=localhost;Database=cadastral_management;Uid=YOUR_USER;Pwd=YOUR_PASSWORD;"
}
```
*Замените `YOUR_USER` и `YOUR_PASSWORD` на ваши логин и пароль от MySQL (например, `root` / `root123`).*

### Шаг 3. Сборка и запуск веб-приложения

#### Через терминал (CLI):
1. Откройте терминал в папке `Cadastral Management` (где лежит `.csproj` файл).
2. Выполните сборку:
   ```bash
   dotnet build
   ```
3. Запустите проект:
   ```bash
   dotnet run
   ```
4. Откройте браузер по адресу: `https://localhost:7111` или `http://localhost:5274`.

#### Через Visual Studio 2022:
1. Откройте файл решения `Cadastral Management.sln`.
2. Установите проект `Cadastral Management` в качестве запускаемого.
3. Нажмите **F5** (с отладкой) или **Ctrl+F5** (без отладки).

## 🧪 4. Автоматическое тестирование

Проект покрыт автоматическими юнит-тестами (всего **21 тест**), проверяющими ключевые бизнес-сценарии (вход, регистрация, подача заявлений, согласование сотрудником, генерация объектов, валидация полей).

Для запуска тестов откройте терминал в корне решения и введите команду:
```bash
dotnet test
```
Тесты используют внутрипамятую базу данных (`InMemoryDatabase`), выполняются изолированно и не требуют запущенного сервера MySQL.

## 💡 5. Ключевые инженерные особенности

* **Настройка локализации чисел (.NET & HTML5):** в РФ разделителем дробной части является запятая `,`, но поля ввода `type="number"` в HTML5 работают исключительно с точкой `.`. В `Program.cs` настроена гибридная культура, принудительно переопределяющая десятичный разделитель на точку, что решает проблему валидации площади при подаче заявлений.
* **Генерация юридических PDF документов:** динамические кадастровые выписки формируются на лету через `iTextSharp`. Они стилизованы под гербовые бланки, включают 4 раздела (сведения об объекте, владельце, историю изменений и расчет налоговой стоимости по ставке 0.3%) и содержат имитированный штамп ЭЦП.
* **Кастомная авторизация на сессиях:** сессии (`ISession`) используются для безопасного хранения контекста авторизованного пользователя и ролей без утяжеления проекта технологией ASP.NET Identity. Пароли в БД надежно хэшируются с помощью **BCrypt**.
